# AssetNexus – Centralized Asset Intelligence Platform

AssetNexus is a role-based asset management system developed as an MCA final year project. It helps organizations manage the complete asset lifecycle, including procurement, allocation, maintenance, returns, and reporting.

## Features

- User authentication and role-based access control
- Asset allocation and tracking
- Asset return request workflow
- Maintenance and service management
- Asset lifecycle monitoring
- Activity logging and audit trail
- CSV/PDF report generation
- Admin dashboard for asset analytics

## Technologies Used

- Python
- Django
- MySQL / SQLite
- HTML5
- CSS3
- JavaScript
- Bootstrap

- Admin
- Employee

## Installation

1. Clone the repository:

   git clone https://github.com/ompatil610/AssetNexus.git

2. Navigate to the project directory:

   cd AssetNexus

3. Create and activate a virtual environment:

   python -m venv venv

   Windows:
   venv\Scripts\activate

4. Install dependencies:

   pip install -r requirements.txt

5. Apply migrations:

   python manage.py migrate

6. Start the development server:

   python manage.py runserver

7. Open your browser and visit:

   http://127.0.0.1:8000/
